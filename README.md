# Offensive Security & Application Auditing Portfolio

This repository contains a curated portfolio of technical security write-ups, vulnerability assessments, and exploit development projects. Each assessment documents real-world attack vectors, mitigation strategies, and architectural hardening guidelines.

## Core Focus Areas
- **Active Directory & Enterprise Security:** Enumeration, delegation attacks (RBCD), and Kerberos ticket manipulation.
- **Binary Reverse Engineering & Analysis:** Static/dynamic analysis using GDB and custom hash recovery workflows.
- **Web & API Penetration Testing:** Exploiting deserialization flaws, SQL injections, and infrastructure misconfigurations.
- **Linux/Windows Privilege Escalation:** Advanced exploitation via SUID binaries, PATH hijacking, and UNIX socket descriptor leaks.

## Repository Structure
- `active-directory-audits/` - Enterprise AD compromises and Kerberos delegation attacks.
- `web-api-pentesting/` - Web applications, deserialization flaws, and API vulnerabilities.
- `binary-reverse-engineering/` - Binary analysis, memory extraction, and hash cracking.
- `system-privilege-escalation/` - Linux/Windows advanced privilege escalation vectors.
